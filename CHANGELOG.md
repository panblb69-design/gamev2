# Changelog

## 0.1.0 — M0 (2026-11-10)

- Nový projekt Factory Empire, Vite/TypeScript/PixiJS.
- Metrová plánovací mapa, kamera, výběr, fixed-step čas a počáteční finance.
- Datové typy budoucích systémů a návrhové katalogy FE-HX001.
- IndexedDB a JSON save/load, validace schématu v1.
- Automatické testy základů, lint/build, česká dokumentace a roadmapa.
- M1–M6 nejsou implementovány.

## 0.2.0 — první výrobní průchod M1

- Skutečné nákupy, hala a stroje s kolizemi, přípojkami a obsluhou.
- Výroba komponent/čištění/montáž, fyzické rezervované přepravy a buffery.
- Zpožděná kooperace, heliový test s karanténou, povrch a balení.
- Zakázky, expedice, faktury a inkaso ve splatnosti, materiálové ocenění.
- Mzdy, jednoduché opotřebení, porucha a oprava s údržbářem a dílem.
- Save v2/migrace M0, testy výrobního průchodu a ovládání v browseru.
- M2–M6 nejsou dokončené; přesná omezení v docs/STATUS.md.

## 0.6.0 — lokální uzavření výchozího rozsahu M2–M6

- M2: fyzické skladové zóny, kg/m³, kontejnery, FIFO a dělené přepravy, VZV, dopravní rezervace, rampy a příjmové sloty.
- M3: nabídky, MRP, výrobní příkazy, rezervace, rámcové odvolávky, sankce, kapacity a cash flow.
- M4: profese/mzdy, směny a týmy, školení, absence a preventivní servis.
- M5: vlastní tavidlo/CAB, kapacitní sítě médií, odpad, genealogie a inspekce.
- M6: časovaný výzkum, roboti, AGV, dopravníky, MES doplňování, OEE a exportní balicí varianta.
- Jádro běží v dedikovaném Web Workeru, má indexy a dávkování/dirty updates; benchmark 144 stanic / 200 lidí / 5000 šarží.
- Save v3, migrace v1/v2, manažerské UI a integrační kampaň všech etap.
- Žádný push ani deployment v této iteraci dle uživatelského požadavku. Přesné hranice v docs/MILESTONE_ACCEPTANCE.md.
